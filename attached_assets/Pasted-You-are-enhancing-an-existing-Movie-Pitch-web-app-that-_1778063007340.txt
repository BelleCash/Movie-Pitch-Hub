🖼️ PART 2 — IMAGE UPLOAD SYSTEM
-----------------------------------

GOAL:
Allow users to upload a movie poster instead of pasting image URL.

IMPLEMENT:

1. Add file input to "Submit Pitch" form

2. Create Supabase Storage bucket:
- Name: "posters"

3. Upload image:

async function uploadImage(file) {
  const fileName = Date.now() + "-" + file.name;

  const { data, error } = await supabase.storage
    .from('posters')
    .upload(fileName, file);

  if (error) return null;

  const { data: publicUrl } = supabase.storage
    .from('posters')
    .getPublicUrl(fileName);

  return publicUrl.publicUrl;
}

4. When submitting pitch:
- Upload image first
- Save returned URL into "image" column
