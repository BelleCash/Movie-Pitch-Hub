## FRONTEND REALTIME LISTENER

Create realtime handler:

```javascript id="realtime"
supabase
  .channel("pitches")
  .on(
    "postgres_changes",
    {
      event: "*",
      schema: "public",
      table: "pitches",
    },
    (payload) => {
      console.log("Realtime update:", payload);
      refreshPitchList();
    }
  )
  .subscribe();
```
