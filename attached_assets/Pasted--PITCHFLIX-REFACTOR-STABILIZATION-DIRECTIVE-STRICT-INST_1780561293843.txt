Under NO circumstance should you delete:

* Source files
* Components
* Pages
* APIs
* Context providers
* Hooks

3. Ask for approval before deletion.

### RULE 2: ASK BEFORE MAKING DESTRUCTIVE CHANGES

Before:

* Renaming files
* Replacing libraries

* Removing routes
* Modifying database schema
* Rebuilding authentication
* Altering billing logic

You MUST:

1. Produce a report.
2. Explain impact.
3. Ask for confirmation.

Do NOT proceed automatically.

### RULE 3: SUPABASE IS THE OFFICIAL BACKEND

Do NOT replace Supabase.

Do NOT migrate away from Supabase.

Treat Supabase as the primary backend for:

* Authentication
* Database
* Storage
* Realtime
* User profiles
* Pitches
* Likes
* Comments
* Follows
* Notifications
* Billing metadata

If alternative backends exist:

* Flag them.
* Report them.
* Do not remove them without approval.
