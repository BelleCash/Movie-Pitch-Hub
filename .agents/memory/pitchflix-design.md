## Rule
Purple only. No red. No orange. No demo/mock/sample/test/prototype language in any user-visible text.

**Palette:**
- Primary: #7c3aed
- Light: #8b5cf6
- Accent: #a855f7
- Dark: #5b21b6
- Background: #0b0b0f
- Surface: #12121a / #14141e

**Why:** PitchFlix is investor-grade. Red = error/danger only (never brand). Any "mock" or "demo" language makes the product look unfinished.

**Known past violation fixed:** FilterBar "Clear filters" button was rgba(229,9,20) red — changed to rgba(124,58,237) purple.
